Personal Project Baseball Machine Learning

Baseball Win Probability

Could I build my own version of a live win-probability bar?

This was an early machine-learning project built around something I already enjoyed: baseball. I used historical game data to see whether a model could estimate a team's chance of winning as the game changed.

The basic idea: update a team's estimated chance of winning as the game develops.

01 · The idea

The project started with a graphic I kept seeing during baseball broadcasts.

A broadcast-style win probability display that inspired the project.

I wanted to understand how a simplified version could be built from historical baseball data. The goal was a general method, but I used the Dodgers as the main proof of concept because they are my favorite team and kept the first version manageable.

02 · How it worked

Turn a game into a snapshot, then ask: which team is more likely to win?

I manually collected historical game records from Retrosheet and reorganized them into a consistent view of the team, opponent, current score, and game situation.

04 · Result

For a small early experiment, the final result was encouraging.

91.9% held-out winner classification accuracy

The final saved experiment correctly classified the eventual winner in about 91.9% of the held-out games.

This number describes winner classification, not whether every displayed probability was perfectly calibrated.

05 · Looking back

It was a baseball passion project that became an early lesson in building an ML project end to end.

I had to collect and clean real data, decide which information mattered, train a model, and then figure out how to test the idea on partial game states rather than only completed games.

Better probability testingCheck whether a reported 70% chance really behaves like 70% over many games.
Future-season testingTrain on earlier seasons and evaluate on later seasons.
Live updatesAutomate game-state updates for a true real-time version.
