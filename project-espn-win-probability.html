Baseball Win Probability

Recreating the idea behind a live win probability bar.

An early machine learning experiment inspired by the win-probability graphics shown during baseball broadcasts. Historical Retrosheet game data was used to explore whether a neural network could estimate how likely a team was to win as a game progressed.

Can game context, the current score, and a team's season performance be combined into a useful in-game win estimate?

01 · The Inspiration

A familiar broadcast graphic sparked the project.

Broadcast reference image used as inspiration for the project concept.

I was interested in the win-probability meters that update throughout live sports broadcasts and wanted to understand how a simplified version could be built for real-time analysis.

The goal was to create a general method predictor that could be used for any team stats. I used the Los Angeles Dodgers (my favorite team) as my main proof of concept, to keep this project manageable.

02 · The Data

Historical games became structured snapshots of game state.

Historical game records were manually collected from Retrosheet and reorganized into a consistent team-versus-opponent representation. I chose a manual workflow rather than building a scraper for ethical reasons.

03 · Model & Approach

The score and game-time matters just as much as the box score

The main modeling idea was that the same statistics should not mean exactly the same thing at every point in a game. A two-run lead in the second inning is different from a two-run lead in the eighth.

05 · Result

A useful proof of concept, with clear next steps.

91.9% Held-out winner classification accuracy

The final saved experiment correctly classified the eventual winner in approximately 91.9% of the held-out test games.

Important: this is classification accuracy, not probability calibration. A stronger version would explicitly evaluate calibration, chronological generalization, and uncertainty before treating the output as a production-quality live win probability.

06 · Reflection

A personal baseball project that became an early ML learning experience.

This project combined two interests: baseball and predictive modeling. It gave me hands-on experience turning messy real-world data into a complete ML workflow — collecting and cleaning data, designing features, training a neural network, and testing it on partial game states.

Looking back, the most valuable part is being able to see what I would improve now with a stronger ML perspective.

Calibration — measure whether a reported 70% really behaves like 70%.
Temporal splits — validate on future seasons instead of only random held-out games.
Live pipeline — automate game-state updates for a true real-time demo.
